# pet-story-E2E

Репозиторий с проектом автоматизации сквозного (E2E) тестирования для API сервиса Pet Story. Создан для демонстрации навыков проектирования тестовых сценариев и автоматизации API-тестов.

## Технологический стек
* **Postman** — написание и структурирование тест-кейсов, работа с переменными окружения.
* **JavaScript / Postman Sandbox** — реализация динамических проверок (тестовых скриптов), обработка ответов, валидация JSON-схем и автоматическая передача токенов авторизации между запросами.
* **Newman** — консольный раннер для интеграции тестов в CI/CD пайплайны.

## Что реализовано в коллекции
* **Позитивные сценарии:** проверка сквозных пользовательских путей от авторизации до управления сущностями.
* **Негативные тест-кейсы:** валидация обработки некорректных данных, граничных значений и проверки прав доступа (400, 401, 403, 404).
* **Автоматизация проверок:** в каждый запрос внедрены скрипты (Pre-request и Tests) для проверки статус-кодов, времени отклика и структуры тела ответа.
